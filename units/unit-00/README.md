# 單元 0：導論與 Coze 平台初探

## 檢核標準

建立 Github Repo 並上傳一份 README 說明產品客服 Agent 的初步構想與使用場景。

## 產出

- 這個 repo
- 根目錄 [README.md](../../README.md)：構想、四個使用場景、元件對應、已知難點

## 為什麼選這個產品

選《加密研究快評》當客服對象，是因為它的知識庫本來就分三層（未查證 / 已驗證 / 已推翻），
後面單元 4 的 Knowledge 和單元 8 的 Guardrail 可以直接對應到這個分層，
不用為了交作業硬湊情境。

代價是知識庫目前只有 6 條已驗證事實，量太小，單元 4 之後可能會撞到問題。
